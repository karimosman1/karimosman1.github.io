# Karim Osman portfolio

Static Jekyll portfolio source for GitHub Pages. The site is published from the repository root on `main`; see `README.md` for local preview and publishing instructions.

- Pages: `index.md`, `about.md`, `work-experience.md`, and `contact.md`
- Shared layout and metadata: `_layouts/`, `_includes/`, and `_config.yml`
- Styling and favicon: `assets/`
- Do not add a framework, backend, database, contact form service, or tracking scripts.
